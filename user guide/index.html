Section 3: Import & Export Attendees via Excel

Step 1: Access Import & Download Template:

  • Go to the Registrations section.
  • Click on Import Excel File.
  • A popup window will appear with two options:
    • Upload Your Excel File
    • Download Template (this ensures you use the correct format for attendee data).

Step 2: Download & Fill the Excel Template

  • Click Download Template to access the Excel file.
  • Once downloaded, open the Excel file and fill in all the listed fields mandatorily in order to successfully import it back into the system.
  • To maintain a unified format, use the dropdown options provided in the file for:
    • Country of Residence
    • Nationality
    • Country Code

⚠️ Please ensure all mandatory fields are completed, otherwise the file cannot be imported.

Step 3: Upload Your Excel File

  • Choose the attendee Excel file from your system.
  • Click Next to proceed.

Step 4: Map Excel Fields with System Fields

  • The system will auto-map Excel columns with the event system fields (e.g., First Name, Last Name, Email, Mobile Number ).
  • Review the mapping and adjust if needed.
  • Click Preview once done.

Step 5: Preview Imported Attendee List

  • Review the attendee details such as Name, Email, Mobile, Company, Job Title in the preview window.
  • Enter the import batch name in the “ Preview “ field. (if needed)
  • If all details are correct, click Submit to finalize the import. Submission will only be allowed if all mandatory fields in the Excel file are completed and properly reflected in this preview.

Step 6: Imported Attendees List

  • The successfully imported attendees will now appear in the Registrations list.
  • From here, you can manage registrations and send communications to your attendees.

Step 7: Export Attendee List

  • To export the registered attendees, click on the Export Excel button available in the Registrations section.
  • The system will generate and download the Excel file with all attendee details.

📤 Section 4: How to Create a Single Badge Entry

The Exhibitor Portal allows you to easily create individual badge entries for your team members. Please follow the steps below:

Step 1: Navigate to the Badges Section

  • From the , click on the Badges menu on the left panel.
  • You will be redirected to the Registrations page where you can manage all your badge entries.

Step 2: Click on Create Single Entry

  • On the Registrations page, click the Create Single Entry button.
  • This will open a form where you can manually enter attendee details.

Step 3: Fill in Attendee Details

  • Enter the required information such as:
    • First Name
    • Last Name
    • Job Title
    • Company Name
    • Country of Residence
    • Nationality
    • Email
    • Mobile Number
    • Ticket Type
  • Make sure all mandatory fields are correctly filled.

Step 4: Save the Entry

  • After filling in the form, you will have the following options at the bottom:
    • Register – Save the entry and submit the registration details.
    • Close – Exit without saving.
  • Make sure all mandatory fields are correctly filled.

✅ Note: Once the badge entry is saved, it will immediately reflect in the Registrations list. You can export the list to Excel anytime for your records.

📊 Understanding the Numbers

Example Scenario from the Screenshot:

Visitor Promo Code (VSTR):

  • Original Allocation: 2 uses
  • Used Quantity: 1 (someone already registered)
  • Reserved Quantity: 1 (invitation sent, awaiting registration)
  • Remaining: 0 (fully allocated)

Student Coupon (****):

  • Original Allocation: 2 uses
  • Used Quantity: 0 (no registrations yet)
  • Reserved Quantity: 1 (one invitation pending)
  • Remaining: 1 (one use still available)

⚠️ Important Notes

  • Reserved quantities are held for sent invitations. If the recipient doesn't register, you may need to cancel the reservation to free up the allocation.
  • Promo codes with 0 remaining allocation cannot be used for new invitations until reservations are cancelled or the allocation is increased.
  • Always check the expiry date before sending invitations to ensure recipients have time to register.

✅ Quick Actions Guide

  • To invite a single person: Click "Broadcast Promocode" next to the specific code
  • To invite multiple people with different codes: Use "Broadcast All Promocodes" button
  • To track invitation status: Click "View Details" or the promo code name
  • To export data for reporting: Use the "Export to Excel" button

🔎 Search & Filter

Use the search box on the top right to quickly find specific promo codes by name or code value. This is especially helpful when managing multiple promo codes.

📤 Section 6: Broadcast Promo Code — Invitation Modal

The Broadcast Promo Code feature allows exhibitors to invite guests to register using a specific promo code. When you click the "Broadcast Promocode" button, you'll see the invitation modal.

🪄 Purpose of the Modal

This modal (titled "Assign Exhibitor coupon" in this example) opens when you click the "Broadcast Promocode" button from the Promo Code Management page. It allows you to:

  • Assign a promo code to one or more guests
  • Send invitation emails automatically
  • Track who received and used the promo code
  • Choose between two button types for sharing:
    • One Time Button: Creates a unique single-use link for each recipient. Once used, the link becomes inactive and cannot be reused.
    • Public Button: Can be used multiple times. The promocode remains visible and can be applied automatically. Recipients can remove and apply other codes if needed.

📝 Form Fields Explained

Field Description
First Name Enter the recipient's first name (required field)
Last Name Enter the recipient's last name (required field)
Email Enter the recipient's email address (required field)
+ Add Entry Click this button to add more recipients. You can invite multiple people at once.

⚠️ All fields required

Note the red text "All fields required" - you must fill in First Name, Last Name, and Email for each recipient before proceeding.

🔧 Button Types Explanation

🔹 One Time Button

How it works:

  • Creates a unique single-use link for each recipient
  • Can only be used once with promocode
  • Promocode remains hidden from user
  • Once redeemed, the link becomes inactive

Best for: Exclusive invitations where you want to ensure each person can only register once

🔹 Public Button

How it works:

  • Can be used multiple times
  • Promocode is visible and automatically applied
  • Users can remove the promocode and apply other codes if they have them
  • Remains active until the promocode's allocation is exhausted

Best for: General invitations where flexibility is needed

📤 How to Use

Enter Recipient Details

Fill in the First Name, Last Name, and Email for your first recipient.

Add More Recipients (Optional)

Click the + Add Entry button to add additional recipients. Repeat for as many people as you want to invite.

Choose Button Type

Select the appropriate button type based on your needs:

  • Click 🎯 One Time for exclusive, single-use invitations
  • Click 📢 Public for flexible, multi-use invitations

Send or Cancel

After clicking your chosen button type, the invitations will be sent automatically.

Or click ✕ Close to cancel without sending.

✅ What Happens Next

After sending invitations:

  • Each recipient receives an email with their personalized registration link
  • The promo code will be automatically applied based on the button type chosen
  • You can track the status of each invitation in the Promo Code Usage Logs (Section 5)
  • The promo code's "Reserved Quantity" will increase to reflect pending invitations

💡 Pro Tip

The modal title changes based on the promo code being broadcast. In this example, it shows "Assign Student coupon" because a student-specific promo code is being used.

📊 Section 7: Promo Code Usage Logs — Detailed View

When you click on a promo code name from the Promo Code Management page, you'll be taken to a detailed Coupon Request Logs screen that helps track and monitor all invitations and redemptions related to that specific promo code.

📸 Usage Logs Screenshot Detailed usage logs interface with summary cards and logs table

🧾 Top Summary Cards

At the top of the page, three summary cards display real-time status of the promo code's usage:

🟡 Pending

Number of invitations sent but not yet redeemed

🔴 Cancelled

Number of invitations that were manually cancelled

🟢 Redeemed

Number of guests who successfully used the promo code to register
(e.g., 0 / 10 means 0 out of 10 allocated uses have been redeemed)

📋 Coupon Request Logs Table

This table provides a line-by-line breakdown of every invitation sent using the selected promo code.

Column Description
No Serial number for each invitation
Batch Name The name given to the group of invitations when the promo was broadcast
Email Email address of the invited guest
URL (May contain a unique registration link — visible in some versions)
Description Description entered during the broadcast for internal tracking
Invited Datetime Timestamp when the invite was sent
Created By Email of the exhibitor admin who initiated the broadcast
Status Status label (e.g., Pending & Reserved, Redeemed, Cancelled)

📌 Status Meaning

Status Definitions

  • Pending & Reserved — The user has received the invite but hasn't yet registered.
  • Redeemed — The user completed the registration using the promo code.
  • Cancelled — The invite or reservation has been manually invalidated or revoked.

🔍 Search Log

Use the search bar in the top-right corner to filter logs by email, batch name, or description.

💡 Pro Tips for Usage Logs

  • Monitor the pending status to follow up with guests who haven't registered yet
  • Use batch names to organize different invitation campaigns
  • Export logs for reporting and analysis purposes
  • Check timestamps to track invitation delivery timing
